# Biology interactive pages · BGCSE 0573 Topic 3 Nutrition, Extension Set 2

One self-contained HTML page per question: Q3.3, Q3.4, Q3.6, Q3.7, Q3.8, Q3.9, Q3.10.
Q3.5 has no page because the set has no diagram-based part for it.

Each page uses the Summit IQ visual system from `maatla/src/shared.css` and `shared.js`, plus `src/bio.css` and `src/bio.js`.
Question wording and mark points come from the Extension Practice Set 2 PDF.

Edit the pages in `src/`, then rebuild:

    python3 build.py
