# Maatla · IGCSE Physics 0625/41 Oct/Nov 2022 illustrations

One self-contained HTML page per question (Q3, Q4, Q7, Q8, Q9). Each page shows the question text, an interactive diagram, a live readout panel and a formula box, plus two slips from Maatla's timed attempt and the mark-scheme points they cost.

Edit the sources in `src/` (`shared.css` and `shared.js` are inlined into every page), then rebuild:

    python3 build.py

Question wording and mark points come from the published Cambridge question paper and mark scheme (© UCLES 2022).
